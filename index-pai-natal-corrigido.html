Perguntas frequentes

Vamos simplificar a magia.

Algumas respostas rápidas antes de marcarmos a experiência.

Onde podem acontecer as experiências?

Em casas, empresas, lojas, hotéis, escolas, eventos e outros espaços. A presença é ajustada ao local e ao tipo de público.

Trabalham com empresas?

Sim. O projeto está preparado para eventos corporativos, ativações, centros comerciais e experiências para clientes e colaboradores.

É possível fazer uma sessão fotográfica?

Sim. Podemos criar uma presença especialmente pensada para fotografias e interação com famílias ou convidados.

Como peço disponibilidade?

Envie-nos a(s) data(s), local, tipo de evento e número aproximado de participantes. Respondemos com a melhor proposta para o momento.

Privacidade

Os seus dados, com transparência.

Os dados preenchidos neste formulário são usados para preparar a mensagem do seu pedido. Ao carregar em enviar, o site abre o WhatsApp com a mensagem preenchida; o envio só acontece quando confirmar na aplicação.

Este site não tem, nesta versão, uma base de dados que guarde os dados do formulário. Depois de abrir o WhatsApp, o tratamento da mensagem passa também a estar sujeito às condições e à política de privacidade do WhatsApp. Inclua apenas os dados necessários para responder ao pedido.

Para esclarecer dúvidas sobre o pedido ou solicitar que uma conversa seja eliminada, utilize o contacto WhatsApp indicado no site.
